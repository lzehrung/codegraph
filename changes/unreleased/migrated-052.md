Ruby: methods of a type that a block builds (`Base = Struct.new(:a) do ... end`, `Class.new`, `Module.new`) belong to the constant, so a subclass, an includer, or the block itself reaches them by bare name and an unrelated class of the same method names does not. A `def object.name` with a receiver other than `self` or the enclosing constant is a method of that object: a bare call inside it records no edge. A bare call of a module's method records an edge only from a type that includes or extends that module, or from a top-level `def` of a file that includes it at the top level; a top-level `def` of another file stays reachable. A bare method name used as a call receiver (`lines.sum`, `items.each { }`) records the call, and a call that depends on `self` (a bare name, `self.x`) inside the block of a receiverless call whose method the file does not show to yield (`mock_app do ... end`) records no edge, since the block may run with another `self`. A call on a constant, a local, or another call (`Tool.make`, `Widget.new`) is still recorded there, and a method of the file that yields, or takes a `&block` it does not evaluate, keeps `self`. `c0&mask`, `c0 -c1`, and `c0 [1]` read the local `c0` when one is bound before, as in Ruby, in go-to-definition.
