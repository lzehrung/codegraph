section: Fixed
---

Java annotation element names resolve to the annotation's own declared elements, and pattern variables bind inside proven `if` and switch-rule flow scopes rather than to same-named fields. Other flow shapes stay conservative without hiding fields outside a pattern's member, lambda, conditional operand, or positive-only `if` branch. Unresolved annotation keys, C# tuple labels, and explicit anonymous-property names do not make references of unrelated declarations partial.
